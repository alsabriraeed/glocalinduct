# Ambiguities, resolutions and departures from the guide

The brief asks for a log of every ambiguity, the chosen resolution, and its compatibility with the
methodology. Items marked **departure** change something the guide states; the rest are resolutions
of points the guide leaves open.

|---|-------|-----------|---------------|
| 1 | Admitted reference Arabic as a demonstration | At admission (eligible only) the Arabic reference is copied from the private store into the demonstration text store. Non-eligible references stay private. The current group is always excluded at retrieval. | Guide §6/§17: accepted examples from other eligible groups may include Arabic; private references must not be resolved by online bundle builders. |
| 2 | Oversized blocks | Paragraph/quote blocks longer than `windows.content_tokens` are split at sentence boundaries **before** the text is frozen (IDs `b0003.1`, `b0003.2`). ## ExpeL learning mode (`learning:` block in `configs/default.yaml`)

`configs/default.yaml` follows *ExpeL: LLM Agents Are Experiential Learners*; the code defaults of
`LearningConfig` keep the guide behaviour described in rows 1, 7, 8 and 10 above. Each switch is independent.

| Switch (ExpeL value) | Behaviour | Guide behaviour it replaces |
|---|---|---|
| `reference_demonstrations: false` | M0 is published empty. References are never admitted or retrieved as demonstrations; they stay private and only supply the success signal during practice. Both learning subsets (seed and practice) are practised. | Rows 1, 7: references were admitted (A1 + A5 checks) and shown as demonstrations. |
| `success_signal: reference_comparison` | Success = the private comparison says `compatible`. A5 stays a diagnostic whose findings feed the reflection. A candidate with an A5 evidence error is still compared unless the error is non-recoverable. | Row 8: success required an A5 pass *and* a compatible comparison. |
| `reflection: free_text` | After each failed, non-final attempt, agent A6 (`prompts/a6_failure_reflection.md`, `LLM_reflect`) writes a short free-text diagnosis from the A5 findings and the sanitised comparison (candidate defects only; no reference text, quotes or comparison summary; leakage guard enforced). Reflections accumulate and always go back through the planner. If A6 fails, structured findings feedback is used. | Row 8: feedback was structured findings only. |
| `pair_every_failure: true` | Each failed attempt gets its own `failure_success` packet with the task's first success. | Only the last failed attempt was paired. |
| `insight_admission: immediate` | An `ADD` is active at once; an insight retires only when its importance reaches 0. | Row 10: provisional until support, A5 checks and group thresholds were met. |

Deviations that remain even in ExpeL mode: A5 still reviews each insight operation before it is committed
(the paper has no such step); inference still applies the deterministic `decide_result` gate and has no
reference; success uses an LLM comparison rather than an environment reward.

Retrieval (`retrieval.*`): `all-mpnet-base-v2` embeddings of the raw source text, cosine kNN with FAISS
`IndexFlatIP` (CPU: exact search is already instant at this scale), all active insights given to the planner.
The embedder runs on the GPU (`retrieval.embedder_device: cuda`; `auto` falls back to CPU with a warning).

## Known limitations (milestone 5 not run)

- No real provider was called; the fake provider's Arabic is a labelled placeholder. No semantic
  quality, cross-domain performance, latency or cost figures exist.
- Dependency versions are not locked (`pyproject.toml` has lower bounds only); pin them after the
  provider is chosen.
- `evaluate` reports counts, macro rates, issue codes and reference compatibility; group-level
  bootstrap intervals and the leave-one-domain-out rebuild are not implemented.
- The hashing embedder and whitespace tokenizer are pilot stand-ins.
